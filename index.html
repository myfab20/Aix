How to use AIX

Get started in 3 steps.

1

Install AIX

Run npm i @cloud-nine-ai/aix then npx @cloud-nine-ai/aix init to scaffold your project with tokens and components.

2

Add Components

Use npx @cloud-nine-ai/aix add button card input to install what you need. Or add pattern dashboard for full layouts.

3

Connect to AI

Add the MCP server to Claude/Cursor/VS Code. Run npx @cloud-nine-ai/aix mcp. Then ask AI to build UI.

Connect to AI agents

How to connect AIX to your AI

Add the AIX MCP server to Claude Desktop, Cursor, or VS Code. Then ask AI to build UI with your components.

// Install AIX
npm i @cloud-nine-ai/aix
// Start MCP server (for AI agents)
npx @cloud-nine-ai/aix mcp
// Claude Desktop config (claude_desktop_config.json)
{
  "mcpServers": {
    "aix": {
      "command": "npx",
      "args": ["@cloud-nine-ai/aix", "mcp"]
    }
  }
}
